# Startap G'oyasi Generatori 🚀

365 kunlik ijodiy loyihalar challenge — **26-kun**.

Zamonaviy SaaS pitch-sahifasi ko'rinishida — lekin har safar mutlaqo ahamiyatsiz kundalik muammoni "sun'iy intellekt" yoki "blokcheyn" kabi baland so'zlar bilan "hal qiladigan" soxta startap g'oyasini yaratadi.

## Xususiyatlari

- 12 prefiks × 10 suffiksdan kompaniya nomi generatsiya qilinadi
- 12 ta ahamiyatsiz muammo va 10 ta texnologik "buzzword" tasodifiy birlashadi
- Tasodifiy bozor hajmi, so'ralayotgan investitsiya va baholash ko'rsatkichlari
- 8 ta kinояли "pitch" jumlasi va 4 ta tasodifiy teg
- Zamonaviy gradient SaaS landing-page dizayni

## Ishga tushirish

`index.html` faylini brauzerda oching. Hech qanday server yoki kutubxona kerak emas.

## Texnologiyalar

- HTML5 / CSS3 (gradient, grid) / Vanilla JavaScript
